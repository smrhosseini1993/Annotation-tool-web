Medical Image Annotation Study Kit

Version: see VERSION.txt in this folder.

1. Place the assigned images in:
   Study_Data\input_images\

   Supported file types: .png, .jpg, and .jpeg.
   Images keep their native dimensions in the annotation workspace.

2. Double-click:
   Start Annotation Tool.bat

3. Your web browser opens automatically. Use Chrome at 100% zoom.

4. Complete the annotation session. Results are saved automatically in:
   Study_Data\results\

5. When finished, close the browser and double-click:
   Close Annotation Tool.bat

The study guide is available in:
   Study_Guide\medical_image_annotation_quick_guide.pdf

Do not rename, move, or delete files inside the application folder.
