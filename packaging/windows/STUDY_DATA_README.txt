Study_Data folder

input_images\
  Put the assigned PET-MPI polar-map images here before starting the app.
  Supported file types: .png, .jpg, and .jpeg.
  All study images must use the standard 1024 x 1024 polar-map layout.

results\
  The tool creates and updates outputs here automatically.
  Keep this entire folder after the annotation session.
  Do not mix results from different experts or sessions in the same Study Kit.
